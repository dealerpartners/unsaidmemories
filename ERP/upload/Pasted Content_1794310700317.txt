How Printful's blank PNG vs Printify's "blank SVG" wash out
They're the same problem once normalized. Both reduce to base image + print rectangle in real units:

Printful → blank product PNG + printfiles dimensions (placement size in inches)
Printify → blueprint placeholder (position + width/height px @ DPI → inches)
Our skeleton model (BlankDetail.printAreas, BlankSkeleton views) already ingests both into one shape. The hard problems are deliberately split: the browser canvas only needs to be proportionally correct (inches math guarantees it), while pixel-perfect print output happens server-side in sharp from the same spec.
